- [ ] 환경변수 **이름** 목록 (Cloudflare Pages 설정 화면)
- [ ] Storage 버킷 사용 여부
- [ ] 업무 규칙: 예약 시간 단위(10/15/30분), 운영 시간, 최대 예약 시간, 반복예약 규칙(매주/격주/매월, 종료 조건), 관리자만 가능한 기능
