# HANA WORKS — 총무 통합 업무 지원 시스템 (디자인 프로토타입)

하나생명 경영지원부의 **총무 업무 지원 / 법인차량 이용 / 회의실 예약 / 인장 날인 관리**를 한 공간에서 제공하는 반응형 UI 시안입니다.

## 현재 포함된 내용
- 통합 대시보드: KPI, 월별 업무 추이 그래프, 업무별 빠른 이동, 최근 신청 테이블
- 4개 서비스 모듈별 화면 및 관리자 화면
- 좌측 메뉴, 모바일 내비게이션, 알림 팝오버, 검색/상태 필터
- 신청 모달과 데모용 신청 추가 동작 (브라우저 메모리에만 반영)
- Framer Motion 화면 전환, 카드 호버, 차트 등장 애니메이션

> **주의**: 디자인 검토용입니다. 가상의 KPI와 신청 데이터를 사용하며, 실제 사용자 인증·DB·신청·승인·차량/회의실 예약 검증은 구현되어 있지 않습니다. 코드를 그대로 업무 운영에 사용하지 마세요.

## 로컬 실행

Node.js 20 이상 권장.

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 접속.

## GitHub 및 Vercel 배포

1. GitHub에서 빈 저장소를 생성하고 해당 프로젝트 파일 전체를 올립니다.
2. Vercel에서 **Add New → Project → Import Git Repository** 를 선택합니다.
3. Framework Preset을 **Next.js** 로 설정하고 **Deploy** 합니다.
4. 현재 디자인 프로토타입에는 별도 환경변수가 필요하지 않습니다.

## 향후 작업

1. 기존 세 앱의 소스/DB 구조 분석 및 스키마 매핑
2. 공통 로그인과 역할별 권한(RBAC/RLS) 및 직원 정보 연결
3. 기존 기능을 모듈로 통합하고 데이터 마이그레이션 검증
4. 인장 신청/승인/날인 완료와 사용대장 데이터 모델 및 감사 로그 구현
5. 실제 KPI/통계 집계, 알림, 파일 관리 및 기능 테스트

## 참고
디자인은 하나생명의 녹색 계열을 활용한 **컨셉 시안**이며 실제 공식 로고 파일을 포함하지 않습니다. 메인 UI의 HANA WORKS 로고 심벌은 임시 그래픽입니다.
