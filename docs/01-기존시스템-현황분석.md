## 3. 1단계를 끝내기 위해 필요한 자료

자료 요청 목록은 [`03-자료요청-체크리스트.md`](./03-자료요청-체크리스트.md)에 있습니다. 가장 먼저 필요한 것은 아래 세 가지입니다.

1. **3개 시스템 소스코드** — GitHub 저장소 이름(이 세션에 연결 가능) 또는 압축 파일
2. **회의실 Supabase 스키마 덤프(구조만)** — `supabase db dump --schema-only` 결과, RLS 정책, 함수·트리거 목록
3. **총무·차량 시스템의 데이터 저장 위치** — 어떤 DB/서비스에 데이터가 쌓이는지

> 참고: 이 개발 환경에서 기존 사이트 두 곳에 접속하려면 클라우드 환경 설정 → Network access에서
> `cosmic-basbousa-bcb062.netlify.app`, `hanalife-meeting.pages.dev`를 Allowed domains에 추가해야 합니다.
> 다만 화면을 보는 것만으로는 DB 구조와 업무 규칙을 확인할 수 없으므로 **소스코드와 스키마 확보가 우선**입니다.
