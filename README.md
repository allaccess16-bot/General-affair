# 하나생명 총무 통합 업무 지원 시스템

경영지원부의 총무 업무 지원, 법인차량, 회의실 예약 시스템을 하나로 합치고, 인장 날인 신청·관리 모듈을 새로 추가하는 통합 업무 포털입니다. 배포 환경은 Vercel입니다.

## 진행 현황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 기존 3개 시스템 구조·기능 분석 | 진행 중 (기존 소스·DB 자료 대기) |
| 2 | 통합 아키텍처·공통 UI 설계 | 초안 작성 |
| 3–7 | 포털, 모듈 연결, 인장 날인, 관리자 센터, 검증·배포 | 대기 |
